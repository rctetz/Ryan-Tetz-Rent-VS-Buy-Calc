HOUSE ALPHA V37 — PHONE APP / SHARING SETUP

WHAT THIS IS
This is an installable Progressive Web App (PWA). Once hosted at an HTTPS web address, it can be:
- opened on iPhone, Android, Mac, or PC
- installed on a phone home screen
- shared with coworkers using one link
- used offline for calculations after the first visit
- refreshed online for current market inputs

EASIEST PUBLIC DEPLOYMENT: RENDER
1. Create a free GitHub account if needed.
2. Create a new GitHub repository and upload every file in this folder.
3. Create a Render account at render.com.
4. Choose New > Blueprint and connect the GitHub repository.
5. Render detects render.yaml. Approve the deployment.
6. In the Render service's Environment settings, confirm these required variables:
   - PROPERTY_LOOKUP_ACCESS_CODE: a private code for trusted detailed-property users
   - PROPERTY_LOOKUP_SESSION_SECRET: a long random secret generated by Render
   - RENTCAST_API_KEY: your private RentCast key
   - HOUSE_ALPHA_ORIGIN: the exact public HTTPS origin, with no path
   Keep the access code, session secret, and RentCast key out of GitHub and browser code.
7. Render gives you an HTTPS link such as:
   https://mammoth-rent-vs-buy.onrender.com
   If your Render URL differs, update HOUSE_ALPHA_ORIGIN to that exact origin and redeploy.
8. Share that link with coworkers. Census address matching remains public. Only trusted users with the private access code can unlock paid RentCast enrichment; successful access creates a signed, time-limited, HTTP-only cookie on that browser.

PROPERTY LOOKUP COST CONTROL
- A common uncached primary-residence enrichment uses 1 RentCast call.
- Rental and live-in enrichment normally use 2 calls because they also request a rent estimate.
- If the active listing is absent or too sparse, House Alpha may make 1 additional property-record fallback call.
- RENTCAST_PROCESS_CALL_LIMIT defaults to 30. This is only a per-server-process emergency ceiling; it resets on restart and is not a durable monthly billing cap. Use RentCast's account quota and billing controls as the real spending guardrail.
- Public Census-only matching does not use the RentCast key.

INSTALL ON IPHONE
1. Open the public link in Safari.
2. Tap the Share button.
3. Tap Add to Home Screen.
4. Tap Add.

INSTALL ON ANDROID
1. Open the public link in Chrome.
2. Tap Install when prompted, or use the menu > Install app / Add to Home screen.

IMPORTANT
- The live data refresh requires the hosted Python backend.
- The app still performs saved/default calculations offline.
- Detailed RentCast enrichment requires the private access code and an online connection; Census-only address matching stays public.
- Property History is stored only in that browser profile on that device. It has no account or cloud sync, so saved properties do not automatically appear in another browser or on another device.
- An optional property photo is resized into a local thumbnail in the browser. It is not uploaded to the House Alpha backend, Census, or RentCast, and it is omitted from shared result text.
- Running Reset clears the working/saved calculator scenario but keeps the separate Property History. Delete a saved property from its history card when you want to remove it.
- Clearing browser site data, using private browsing, or removing browser storage can erase Property History and its thumbnails.
- Public-source page layouts can change and break automated data extraction. The app always keeps values editable and shows fallback data.
- HOA and insurance are planning benchmarks, not exact quotes.
- Stock-return inputs are effective annual returns and are compounded at the equivalent monthly rate.
- Saved comparisons include automatic/manual input flags and the calculation version, preventing unlike model versions from being presented as a valid delta.
